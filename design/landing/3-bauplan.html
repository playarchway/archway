Windows games on a Mac, built from parts you can check.

Archway doesn’t reinvent Windows compatibility. It puts Wine, Rosetta and Apple’s D3DMetal together, runs Windows Steam out of sight and gives you a native library to play from. Every part is named, versioned and replaceable.

For the curious

The app shares its core with the archway command line tool, so anything the app does you can repeat and inspect.

# where does everything live?
archway locations

# build the app yourself
scripts/build-app.sh release
open .build/Archway.app

Load limits

What this arch is not rated for, written down before anyone asks:

  • Every Windows game, in particular AAA titles
  • Kernel anti-cheat and arbitrary DRM
  • Intel Macs, and macOS 28 is not promised while Rosetta’s future is open
  • Being a store or replacing Steam

Get Archway

Download the app, or build it from source with Swift 6.4. On first start it fetches its runtime, about 145 MB, and verifies the checksum.
